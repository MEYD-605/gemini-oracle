# Learned knowald/ha-fusion

- **Architecture & Performance**: Built on SvelteKit 2 + Svelte 5 (`{ runes: true }`), compiling down to raw DOM operations without virtual DOM or Shadow DOM overhead. Connects directly to Home Assistant via `home-assistant-js-websocket` with WebSocket push subscriptions.
- **Customization Depth**: Drag-and-drop WYSIWYG editor powered by `sortablejs` and Konva 2D canvas (floorplans). Directly persists to `./data/dashboard.yaml` and `./data/configuration.yaml` with custom CSS/JS injection and YAML theming.
- **HAOS & Smart TV Suitability**: Highly suitable for low-spec Smart TVs (like Sony BRAVIA MT5891 2GB) due to low client memory footprint (~120-150MB) and optimistic UI execution, though D-pad spatial navigation benefits from an air mouse or kiosk pointer mode (`?menu=false`).
