## 3. Recommended Thresholds & Multi-Face Rules for `cull.py`

1. **Detect ALL Faces in Every Frame (`num_faces=5`):**
   - Run MediaPipe `FaceLandmarker` (`num_faces=5, min_face_detection_confidence=0.25`) both on the full image AND on each `melina` person-box crop (deduplicate overlapping face boxes by IoU `> 0.4`).
2. **Closed / Half-Closed Eye Gate (Catches `#76`, `#82`, `#95`):**
   - For **every foreground face** (face width `>= 3.5%` of image width):
     - Read MediaPipe blendshapes:
       - `blink_max = max(eyeBlinkLeft, eyeBlinkRight)`
       - `blink_mean = 0.5 * (eyeBlinkLeft + eyeBlinkRight)`
       - `squint_mean = 0.5 * (eyeSquintLeft + eyeSquintRight)`
       - **Eye Aspect Ratio (EAR)** from landmarks (`upper_lid` vs `lower_lid` / `eye_width`).
     - **Hard Cut (`closed_eyes`):**
       - Lower threshold from `0.70` ➔ **`blink_max >= 0.45`** (or `blink_mean >= 0.38`, or `blink_max + 0.35 * squint_mean >= 0.52`).
       - **Burst-Relative Eye Drop:** If within the same burst (`Δt <= 4s`), a person's `eye_open_score` (`1 - blink_max`) in frame `i` is **`>= 0.18` worse** than their best open-eye frame in that burst, **CUT frame `i` immediately**! (This guarantees `#76`, `#82`, `#95` lose to their open-eye burst neighbors `#75/#77`, `#81/#83`, `#94/#96`).
3. **True Eye-Box Sharpness + `cloudy` (Replaces broken `the_four_kings` face blur):**
   - Instead of running `the_four_kings` on the head box, compute Laplacian/Tenengrad sharpness specifically on the **left + right eye crops** (from face landmarks) + `cloudy/model.onnx` logits.
4. **Expression & Pose Score (`rennala` + `mimic_tear` + `candid` + MediaPipe):**
   - Combine `rennala` (`emotion`), `mimic_tear` (`eyegaze`), `candid` (`candid_score`), and MediaPipe `mouthSmile - (mouthFrown + mouthPucker + jawOpen_mid_speech)` to rank frames inside a burst.

## 4. Upgraded `gemini_look.py --cull`: Comparative Burst + 1:1 Face Crop Strip

Never send a single full-frame `1536px` image in isolation. Instead:

### Step A: Build a Composite Image with 1:1 Face Crops at the Bottom
For each candidate frame:
1. Take the main image resized to `1280px` wide.
2. Crop **every detected face at 1:1 native resolution** (padded to `320x320px` per face, with a red/yellow label `Face 1 (L-eye/R-eye)`, `Face 2`, etc.) and **stitch that horizontal strip directly below the main frame**.

### Exact Drop-In Code for `cant_see` in `cull.py`:
```python
CANT_SEE = sess("ai_models/cant_see/model.onnx")

def eyes_open_prob(im, lms, w, h):
    xs = [p.x * w for p in lms]
    ys = [p.y * h for p in lms]
    cx, cy = 0.5 * (min(xs) + max(xs)), 0.5 * (min(ys) + max(ys))
    r = max(max(xs) - min(xs), max(ys) - min(ys)) * 0.75
    crop = im.crop((max(0, int(cx - r)), max(0, int(cy - r)), min(w, int(cx + r)), min(h, int(cy + r))))
    x = (np.asarray(crop.resize((224, 224), Image.BILINEAR), dtype=np.float32) / 255.0).transpose(2, 0, 1)[None]
    probs = CANT_SEE.run(None, {"input": x})[2][0]  # class_probabilities_primary [5]
    # probs[2] = OPEN, probs[0] = CLOSED, probs[3] = HALF_CLOSED/DROOPY
    return float(probs[2]), float(probs[0]), float(probs[3])
```
