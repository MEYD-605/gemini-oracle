## 2. The 5-Step Development Algorithm (Mandatory)

All Buddy Work between No.6 and No.8 strictly adheres to the 5-step sequence (1 → 2 → 3 → 4 → 5):

1. **Make Requirements Less Dumb**: Clarify actionable constraints, identify direct owner, eliminate vague specifications.
2. **Delete the Step / Part**: Strip away unnecessary polling layers, duplicate proxies, and redundant wrappers. If 10% isn't added back later, not enough was deleted.
3. **Simplify & Optimize**: Refactor the remaining components for maximum throughput and minimal complexity.
4. **Accelerate**: Speed up the manual build and compilation feedback loop to hardware limits.
5. **Automate**: Build scripts and continuous pipelines only as the final step.
