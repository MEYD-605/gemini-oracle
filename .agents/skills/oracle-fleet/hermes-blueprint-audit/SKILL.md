# Hermes Blueprint Audit & Enterprise Architecture Standard

## Core Directives
1. **Audit First, Accept Never**: When user provides an architecture summary or system checklist, do NOT passively agree or claim completeness without conducting a live system audit (cross-checking system tools, 9router proxies, ARRA vault, and active skills).
2. **Proactive 22-Pillar Master Blueprint**: Expand initial simple lists to the full 22-pillar enterprise architecture immediately without waiting for follow-up prompts.
3. **Synchronized Documentation**: Every master architecture update must be recorded in repo SSOT (`HERMES_MASTER_BLUEPRINT.md`) and synced to shared memory (`arra_learn`).
