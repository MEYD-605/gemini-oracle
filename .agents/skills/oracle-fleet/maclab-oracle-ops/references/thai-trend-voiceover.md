# Thai trend research / voiceover pack

Use when Bo asks for current Thailand shopping trends, especially Shopee / live commerce / consumer behavior, and wants a short-form video voiceover.

## Sourcing order
1. Prefer the most current social signal source available.
2. If web search is unavailable or incomplete, use X search for live/social shopping sentiment.
3. If live web sources are still thin, fall back to local Oracle/session_search notes for structure and phrasing.

## Output shape
Keep it terse and in Thai:
- 5 concise bullets
- 1 voiceover script (1–2 sentences)
- 1 alternate punchier version

## Tone rules
- Thai, punchy, no lecture
- Focus on behavior + product clusters + buying triggers
- Mention practical/value buying, live commerce, reviews, vouchers, and repeat-use items when supported
- Avoid overexplaining source limitations in the final deliverable

## Good template
- ไลฟ์ยังเป็นตัวปิดการขาย
- หมวดบิวตี้/แฮร์แคร์ยังแรง
- Home & Living ขายดีเมื่อช่วยชีวิตประจำวันจริง
- แฟชั่นต้องใส่ง่าย ดูแลง่าย
- คนไทยตัดสินใจจากคุ้ม + รีวิวจริง + โปร

Voiceover:
คนไทยยังช้อป Shopee แบบเน้นคุ้ม เห็นของจริงผ่านไลฟ์ แล้วค่อยกดซื้อ หมวดที่ยังแรงคือบิวตี้ ของใช้บ้าน และแฟชั่นใส่ง่าย

Punchier:
Shopee ไทยยังแรงเพราะไลฟ์ โปร และรีวิวจริง คนไทยไม่ได้ซื้อแค่ของถูก แต่ซื้อของที่คุ้มและใช้ได้จริง
