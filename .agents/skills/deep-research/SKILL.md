# Deep Research & Intelligence Protocol

Use this skill when conducting deep technical research, architectural benchmarking, or landscape analysis.

## Execution Steps
1. Multi-Source Discovery: Search online repositories, community hubs (Reddit, GitHub, Arxiv), and documentation.
2. Knowledge Synthesis: Synthesize findings into structured insights without superficial summaries.
3. Artifact Recording: Record key findings in project artifacts and synchronize with Arra Memory if applicable.
